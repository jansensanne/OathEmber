# OathEmber

OathEmber leverages Cloud-Native architecture for Real-Time Processing and Auto-Scaling on a Microservices Framework.

OathEmber is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/OathEmber.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure OathEmber, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
